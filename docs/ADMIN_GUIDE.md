```
本地开发: http://localhost:37000/admin
上线后:   https://naracharm.com/admin
```

> ⚠️ 当前为**开发模式**，后台暂无登录验证（任何人可访问）。上线前我会加管理员登录。

## 三、商品管理（最常用）

### 查看商品列表
点左侧「商品管理」。看到表格：商品名、系列、品类、价格、库存、状态、操作。

### 新增商品
1. 点右上「新增商品」
2. 填写表单：
   - **商品名**：必填，如 `Amethyst Peace Bracelet`
   - **副标题**：选填，如 `Natural amethyst · the stone of calm`
   - **URL标识**：留空，自动从商品名生成
   - **品类**：手链/项链/手机挂链/耳钉
   - **文化来源**：藏/蒙古/西南/泰/汉/融合
   - **系列**：选 Crystal Collection / Phone Charms
   - **售价**：美元数字，如 `38`
   - **划线价**：选填，填写实际使用的参考价格
   - **简短描述**：列表页和分享卡用
   - **工艺故事**：详情页的 Story 区块（按 STORY_DOCTRINE 四层写）
   - **实物资料**：填写已确认的材质和保养说明
   - **SKU 和初始库存**：SKU 可按商品网址自动生成。填写手头可销售的库存数量
   - **状态**：草稿、在售或已下架
   - **首页推荐**：优先展示在首页「Available to order」
3. 点「保存」。系统会同时建立商品、SKU 和库存记录。

### 从设计预览建立商品

在商品管理点「从设计预览建草稿」，按名称或系列选中设计并建立草稿。草稿沿用原网址和系列。填写已确认的实物资料、售价和库存后，将状态设为「在售」。导出和构建后，正式商品会出现在原网址，系列和目录各显示一条记录。

### 编辑商品
点商品行的「编辑」按钮，改完保存。编辑库存时输入实物总量，列表会显示扣除待付款订单预留后的可用数量。

同款有多个规格时，在编辑窗口给各 SKU 填写可识别的规格名称。点「添加 SKU 规格」可填写新 SKU、规格名称、价格和库存。规格价留空时沿用商品售价。保存并更新前台后，顾客可在原商品页选择规格，价格和最大可购数量跟随当前选择。订单及确认邮件会显示所选规格。

### 批量导入商品

在商品管理打开「批量导入」。可下载设计采集表、待补实拍表或空白表。设计采集表保留每款的原网址和系列。每份文件最多 200 条，用 CSV UTF-8 保存，美元售价使用小数点，材质用 `|` 分隔。

- `draft` 建立或更新单 SKU 草稿。草稿可留空实拍、售价和库存字段。
- `publish` 建立在售商品或将草稿上架。填写已核实的描述、材质、美元售价、库存和主图。库存填 `0` 时页面显示缺货。
- `photo` 按商品网址给已有商品补主图。填写 `photo_url`，核对照片对应实物后在 `photo_verified` 填 `yes`。

上传后先点「预检清单」。修正提示的行，再点「应用批次」。批次一次提交，预检后记录变化时需重新预检。公开主图可使用稳定的 HTTPS 地址，或已经随网站部署的 `/products/photos/…` 路径。完成后重新导出目录和构建，核对商品页、库存与 Shopping Feed。

预检表逐行显示实拍缩略图、原始尺寸和加载状态，点击缩略图可看原图。尺寸不足 500 × 500 的照片会标记。请确认能打开原图，并且照片对应当前款式。静态打包也会核查已确认的站内实拍，对缺失、无法读取或扩展名与图像格式不符的文件报告对应款式。

后台不可用时，可在仓库根目录从当前前台快照生成相同格式的采集表。设计表按现有网址和系列预填基础字段，待补实拍表按商品网址生成。填写设计表时，仅将已核实售价、库存、实物材质、描述和实拍的行改为 `publish`。提交实拍批次前，保留已填照片的行。

离线预检会逐行核对表格字段和 `/products/photos/…` 是否存在于前台的 `public` 目录。公开 HTTPS 图片和后台当前的 SKU、库存仍需在应用前核对。

```bash
pnpm --filter web catalog:offline studio "$PWD/nara-studio-intake.csv"
pnpm --filter web catalog:offline photos "$PWD/nara-missing-photos.csv"
pnpm --filter web catalog:offline check "$PWD/nara-studio-intake.csv"
pnpm --filter web catalog:offline snapshot "$PWD/nara-studio-intake.csv" /tmp/nara-products-candidate.json
```

`snapshot` 命令生成独立的候选目录文件。它会检查现有网址和 SKU，按商品网址补实拍，或把资料齐全的新款加入目录。草稿行保留在 CSV 中。启用结账前，新增货品与 SKU 需要同步到订单系统使用的商品数据库。

超过 200 行时可在输出文件名后加页码分批生成。工具遇到同名文件时会停止，避免覆盖已填写的数据。`check` 复用后台的 CSV 解析和字段验证。导入前还需在正式后台预检，以核对当前 SKU、商品状态、库存预留及实拍。

### 添加商品实拍

在商品行打开「图片」，填写与该款商品一致的公开 HTTPS 图片地址。照片只对应某个颜色或材质时，在「适用规格」选择该 SKU。照片适用于每个规格时可选择「所有规格通用」。同一规格的第一张实拍会成为主图，后续可在图库中切换。

重新导出目录后，商品页、购物车和购物 Feed 会按照选中的 SKU 使用对应照片。旧参考图继续保存在后台。生产后台启用规格实拍前需要应用 `0006_variant_photos.sql`。

### 上下架
点「下架」或「上架」，也可以在编辑表单里选择状态。重新导出并构建后，已下架商品会从在售目录移除。工作室仍会展示对应的设计预览。

### 删除商品
点红色垃圾桶图标 → 确认。**删除不可恢复**，建议用「下架」代替删除。

## 四、订单管理

### 查看订单
点「订单管理」。看到所有订单：订单号、顾客邮箱、金额、状态、支付状态、物流、时间。

点「订单详情」，核对顾客下单时选择的规格、SKU、数量和收货地址。商品之后改名或下架，订单会保留原来的明细。

### 订单状态说明
| 状态 | 含义 |
|---|---|
| pending | 待处理（下单未付款） |
| paid | 已支付（待发货） |
| fulfilled | 已发货 |
| cancelled | 已取消 |
| refunded | 已退款 |

> 顾客打开付款页时建立待付款订单并预留库存。Stripe 确认成功后更新为已付款。付款过期后释放预留库存。

### 登记物流

在已付款订单详情中填写承运商、运单号及发货进度。全部出库时选「全部商品已发出」，分包时选「还有商品待发货」。保存后顾客即可查询物流。需要邮件时，在包裹旁点「发送发货通知」。

## 七、优惠券

### 创建优惠券
1. 点「新建优惠券」
2. 填：
   - **优惠码**：如 `WELCOME10`（顾客结账输入）
   - **类型**：百分比 / 固定金额 / 免运费
   - **优惠值**：百分比填 0-100；固定金额填美元数字
   - **最低消费**：选填，如 `50` 表示满 $50 可用
   - **使用次数上限**：选填，留空则不限
   - **有效期**：选填，留空则永久
3. 点「创建」

### 管理优惠券
列表显示所有优惠券 + 使用次数 + 状态。点垃圾桶删除。

> 优惠券的**结账应用逻辑**待开发（目前后台能创建，但前台结账页还没接入优惠码输入框）。

## 八、日常运营建议

### 上新品的流程
1. 在「商品管理」新增商品，或从现有设计建立草稿。
2. 填好商品信息、售价和库存，保存草稿。
3. 在商品行的「图片」添加实拍并确认主图。
4. 将状态设为「在售」。按需要打开首页推荐。
5. 重新导出目录并构建，确认前台图片、售价和购买按钮。

### 看库存
仪表盘会显示「低库存预警」。库存 ≤ 阈值（默认 5）的商品会标红。
去商品管理页 → 该商品的库存列看数量。

### 处理订单（待支付接入）
支付功能接通后：
1. 在「订单管理」打开已付款订单，核对商品与收货地址。
2. 打包发货后录入运单号，保存发货进度。
3. 按需要发送通知。全部商品发出后，订单状态为「已发货」。

## 九、常见问题

### Q: 后台改了商品，前台没更新？
A: 前台读取构建时的目录。导出最新商品数据并构建后，发布新版，再通过前台商品网址确认。

### Q: 图片怎么传？
A: 在商品行打开「图片」，用「添加商品实拍」保存公开的 HTTPS 图片地址。需要更换主图时，在同一个窗口操作。

### Q: 不小心删了商品怎么办？
A: 删除不可恢复。但可以重新新增。建议用「下架」代替删除。

### Q: 后台密码是多少？
A: 开发模式暂无密码。上线前我加管理员登录。

### Q: 怎么加新的品类/筛选？
A: 找我改代码（`src/lib/categories.ts`）。
